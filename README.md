# MyKos (prototype)

Prototype aplikasi pencarian kos untuk mahasiswa UBAYA. Proyek Design Thinking KP I, Kelompok 4.

- `index.html`: prototype aplikasi seluler (klik untuk mencoba)
- `website.html`: versi website

Semua data adalah contoh. Belum ada backend, pembayaran, atau verifikasi sungguhan.

## Menjalankan di komputer
Buka `index.html` di browser. Tidak perlu instalasi.

## Deploy ke Vercel
1. Push folder ini ke GitHub.
2. Di vercel.com pilih Add New > Project, lalu Import repository ini.
3. Framework Preset: Other. Biarkan pengaturan lain kosong, klik Deploy.
